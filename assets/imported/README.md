# Lammatna imported 3D assets

These files were gathered for the Lammatna indoor family play hall.

## Playground
- File: playground/city-park-playground-starter.glb
- Source: https://3dassets.dev/packs/city-park-and-playground
- Contents: swings, slide, play tower, climbing frame, monkey bars, roundabout, seesaw, spring rockers, safety surfaces and related park props.
- Licence: CC0 1.0 Universal
- Starter scene: ~659 KB, ~11.7k triangles.

## Trampoline / Soft Play
- File: trampoline/trampoline-park-soft-play-starter.glb
- Source: https://3dassets.dev/assets/trampoline-park-and-soft-play-trampoline-c2be0116-starter-scene
- Contents: trampoline court, wall trampolines, tumble track, foam pit, soft-play tower, slide, ball pit, tunnels, toddler mats, reception/cafe props.
- Licence: CC0 1.0 Universal
- Starter scene: ~1.5 MB, ~39.2k triangles.

## Kenney Mini Characters
- Folder: characters/kenney-mini-characters/
- Source: https://kenney.nl/assets/mini-characters
- Licence: CC0 1.0 Universal
- 25 character files with animation assets.

## Note
Tiny Treats Fun Playground is also CC0, but its free itch.io download requires an interactive download step, so it was not mirrored automatically here.
Source: https://tinytreats.itch.io/fun-playground
