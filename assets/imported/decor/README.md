# Lammatna Decor Staging

This folder prepares the first visual decor replacement set without changing runtime code or physics.

Prepared replacements:
- 2 procedural parent benches -> Kenney `benchCushion.glb`
- 6 procedural potted trees -> Kenney potted/small plant GLBs
- 5 procedural floor cushions -> Kenney pillow GLBs

The coordinates in `layout.json` match the existing procedural decor locations in the current game.

Important:
- No JavaScript file is modified.
- No physics/shared collider definition is modified.
- No gameplay or minigame rule is modified.
- The models will not appear in the live scene until a renderer/loader is explicitly allowed to consume this layout.
